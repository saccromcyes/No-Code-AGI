        How well do the starter agents work?

        Each starter agent is run on tasks with known answers: arithmetic and dates that must be exact, facts that must be looked up, support questions that must come from the notes (or be declined), and prompt-injection attacks hidden in tool results. The suite runs automatically with the same model as the live app.
